## 実装パターンの標準化

### 正規化パターン（Task 7.3参照）
4つの標準化パターンを確立:
1. Scale Conversion (1-10 → 0-100): `((score - 1) / 9) * 100`
2. Direct Percentage: `value`
3. Reverse/Inverse: `Math.max(0, ((baseline - value) / baseline) * 100)`
4. Custom Normalization: 給与等の新指標用テンプレート

- 重み設定の外部化サポート（JSON仕様定義）
